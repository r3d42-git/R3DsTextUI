# TextUI 0.3.0

macOS 15+ · Apple Silicon · Build 7 · GPL-3.0-or-later

## Deutsch

- XML-Dateien mit der Endung `.xml` werden unabhängig von Groß- und Kleinschreibung erkannt und lassen sich öffnen, bearbeiten und speichern.
- XML erhält Syntaxfarben für Deklarationen, Namespaces, CDATA und Kommentare sowie eine aufklappbare Offline-Strukturvorschau.
- Fehlerhaftes XML zeigt Zeile und Spalte; der Quelltext bleibt bearbeitbar und speicherbar.
- Vorschau und Speichern erhalten Quelle, Kodierung, BOM und Zeilenenden. Die Vorschau führt keine Skripte oder XSLT aus; DTDs und externe Entitäten sind deaktiviert.
- Die XML-Vorschau ist auf 4 MiB Eingabetext und 128 Ebenen begrenzt. Diese Vorschaugrenzen schränken das Bearbeiten nicht ein.

85 lokale Tests bestanden: 59 Core- und 26 native Editortests. Die XML-Oberfläche wurde lokal geprüft und abgenommen.

## English

- XML files with the `.xml` extension are detected case-insensitively and can be opened, edited, and saved.
- XML syntax highlighting covers declarations, namespaces, CDATA, and comments, with a collapsible offline structure preview.
- Malformed XML shows its line and column; the source remains editable and saveable.
- Previewing and saving preserve the source, encoding, BOM, and line endings. The preview runs no scripts or XSLT; DTDs and external entities are disabled.
- The XML preview is limited to 4 MiB of input text and 128 nesting levels. These preview limits do not restrict editing.

85 local tests passed: 59 core and 26 native editor tests. The XML interface was checked and approved locally.
