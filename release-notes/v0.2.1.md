# TextUI 0.2.1

macOS 15+ · Apple Silicon · Build 6 · GPL-3.0-or-later

## Deutsch

- Swift Markdown für die lokale Markdown-Vorschau von 0.7.3 auf 0.9.0 aktualisiert; swift-cmark bleibt bei 0.9.0. Drittanbieterhinweise und Dokumentation sind nachgeführt.
- Minimap-Test stabilisiert: Er wartet auf den tatsächlichen Dokumentindex statt auf eine feste Zeitspanne. Die bisherigen Prüfungen bleiben erhalten; das Laufzeitverhalten der Minimap wurde dabei nicht geändert.
- GitHub-Actions-Checkout auf 7.0.1 aktualisiert und Dependabot-Konfiguration sowie Projektdokumentation gepflegt.

72 automatisierte Core- und native Editortests bestanden. Die lokale Markdown-Vorschau wurde mit einem synthetischen Dokument geprüft.

## English

- Updated Swift Markdown for the local Markdown preview from 0.7.3 to 0.9.0; swift-cmark remains at 0.9.0. Third-party notices and documentation have been updated.
- Stabilized the minimap test: it waits for the actual document index instead of a fixed delay. Existing assertions remain in place; this change does not alter minimap runtime behavior.
- Updated GitHub Actions checkout to 7.0.1 and maintained the Dependabot configuration and project documentation.

72 automated core and native editor tests passed. The local Markdown preview was checked with a synthetic document.
