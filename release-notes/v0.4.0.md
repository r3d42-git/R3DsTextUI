# TextUI 0.4.0

macOS 15+ · Apple Silicon · Build 8 · GPL-3.0-or-later

## Deutsch

- **Shell und Python:** `.command` und `.py` werden als eigene Textformate erkannt, mit Syntaxfarben für Kommentare, Strings, Schlüsselwörter, Zahlen sowie Shell-Variablen und Python-Definitionsnamen. Öffnen, Bearbeiten, Speichern und Entwurfswiederherstellung sind integriert. Bestehende Dateirechte bleiben erhalten; TextUI führt Skripte nicht aus.
- **Reaktionsfähige Suche:** Suchen und Ersetzen arbeiten im Hintergrund. Neue Eingaben brechen ältere Suchläufe ab; zu aufwendige reguläre Ausdrücke enden mit einem Hinweis. Schnell aufeinanderfolgende Suchbefehle bleiben geordnet, Ersetzungen wörtlich und rückgängig zu machen.
- **Schnellere Navigation und Sicherung:** Die Cursoranzeige verwendet einen gemeinsamen Zeilenindex. Entwürfe werden im Hintergrund gesichert; Cursor-/Scrollpositionen und der aktive Tab verwenden kleine separate Checkpoints. Bestehende Sitzungen bleiben lesbar. Bewusstes Speichern, Schließen und Beenden sichern den aktuellen Stand in geordneter Reihenfolge.
- **Übersichtlichere Oberfläche:** Aktive Tabs werden automatisch ins Sichtfeld gescrollt, lange Dateinamen mittig gekürzt. Die Trennlinie zwischen Quelltext und Vorschau lässt sich verschieben. Die Minimap passt ihre Breite an oder blendet sich bei Platzmangel vorübergehend aus, ohne die Nutzereinstellung zu verwerfen.
- **Korrekte Zeilenpositionen:** Unicode-Zeilentrenner am Dateiende erzeugen nun auch in Statusleiste und Navigation die richtige nächste Zeile.

119 lokale Core- und Editortests prüfen unter anderem Abbruch, Undo/Redo, Dateiformate und Dateirechte, Sicherungsreihenfolge, Sitzungswiederherstellung, Unicode und schmale Ansichten. Die native Oberfläche wurde lokal geprüft; der Nutzer hat die aktuelle Entwicklungsversion abgenommen.

Die Skripthervorhebung ist ein leichter Tokenizer: keine Sprachvalidierung, keine gesonderte Here-Doc-Auswertung; Shell-Substitutionen und Python-F-Strings erhalten jeweils eine durchgängige Farbe. Für Skripte gibt es keine Dokumentvorschau.

## English

- **Shell and Python:** `.command` and `.py` are recognized as distinct text formats, with syntax colors for comments, strings, keywords, numbers, shell variables and Python definition names. Opening, editing, saving and draft recovery are integrated. Existing file permissions are preserved; TextUI does not execute scripts.
- **Responsive search:** Find and replace run in the background. New input cancels older searches, and overly expensive regular expressions stop with a message. Rapid search commands remain ordered; replacements stay literal and undoable.
- **Faster navigation and checkpoints:** Cursor status reuses a shared line index. Drafts are saved in the background, while cursor/scroll positions and the active tab use small separate checkpoints. Existing sessions remain readable. Explicit save, close and quit operations save the latest state in order.
- **Clearer interface:** Active tabs scroll into view automatically, and long filenames truncate in the middle. Drag the divider between source and preview to adjust their widths. The minimap adapts its width or temporarily hides when space is tight, preserving the user's preference.
- **Correct line positions:** Trailing Unicode line separators now produce the correct next line in status and navigation.

119 local core and editor tests cover cancellation, undo/redo, file formats and permissions, write ordering, session recovery, Unicode and narrow layouts. The native UI was checked locally, and the user accepted the current development version.

Script highlighting is a lightweight tokenizer: no language validation or dedicated here-document handling; shell substitutions and Python f-strings each receive one continuous color. Scripts have no document preview.
