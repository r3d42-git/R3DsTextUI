# TextUI 0.2.0

macOS 15+ · Apple Silicon · Build 5 · GPL-3.0-or-later

## Deutsch

- Neue Minimap: farbige Dokumentübersicht, in der Struktur und Einrückungen erkennbar bleiben. Der Ausschnitt folgt langen Dateien; Klick, Ziehen und Mausrad navigieren durch den Text. Der Schalter in der Fußleiste blendet sie dauerhaft ein oder aus.
- Zeilennummern und Spaltenleiste lassen sich unabhängig schalten. Die Spaltenleiste folgt Schriftgröße und horizontalem Scrollen; ein Dreieck zeigt die sichtbare Einfügeposition.
- Hell, Dunkel oder System lassen sich als dauerhaftes Erscheinungsbild wählen. Hellere dunkle Fensterflächen und stärker gerundete Tabs verbessern die Orientierung.
- Hänger beim Farbwechsel behoben: Darstellungsaktualisierung und TextKit-Größenabgleich wurden aufeinander abgestimmt.

72 automatisierte Core- und native Editortests bestanden.

## English

- New minimap: a colored document overview that keeps structure and indentation recognizable. Its moving window follows long files; click, drag, or use the mouse wheel to navigate. A persistent bottom-bar toggle shows or hides it.
- Line numbers and the column ruler can be toggled independently. The ruler follows font size and horizontal scrolling; a triangle marks the visible insertion point.
- Choose and retain Light, Dark, or System appearance. Brighter dark window surfaces and more rounded tabs make the interface easier to follow.
- Fixed a hang during light/dark switching by coordinating appearance updates and TextKit document sizing.

72 automated core and native editor tests passed.
