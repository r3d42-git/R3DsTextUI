# TextUI 0.1.3

Dieses Update stellt die Developer-ID-Signierung des Release-Pakets auf das G2-Zertifikat um. Das Release-Skript wählt es standardmäßig über den eindeutigen SHA-1-Fingerabdruck `D548540E7FE1BD9B3C4518CC02D8786E1BFEB885`. So wird bei gleichnamigen Zertifikaten die richtige Identität gewählt; `SIGNING_IDENTITY` bleibt als Override verfügbar. Vor dem Build prüft das Skript, ob die gewählte Identität gültig verfügbar ist.

Die App-Funktionen bleiben gegenüber 0.1.2 unverändert.
