# TextUI 0.1.2

JSON-Dateien lassen sich jetzt öffnen, mit Syntaxfarben bearbeiten und speichern. Die zuschaltbare Offline-Vorschau (⌥⌘P) prüft JSON und zeigt es lesbar eingerückt an, ohne den Quelltext zu verändern. Bei Fehlern erscheinen Zeile und Spalte; auch unvollständiges JSON bleibt bearbeitbar und speicherbar.

- Schlüsselreihenfolge, doppelte Schlüssel, große Zahlen und String-Escapes bleiben in der Vorschau erhalten.
- Bestehende Kodierung, Zeilenenden, Entwurfssicherung und Konflikterkennung gelten auch für JSON.
- README in Deutsch/Englisch und interaktive Architekturseite um JSON ergänzt.
- 55 automatisierte Tests; JSON-Oberfläche lokal geprüft und vom Nutzer bestätigt.

Die Vorschau unterstützt Standard-JSON, keine JSONC-Kommentare oder nachgestellten Kommas; maximal 256 Verschachtelungsebenen.

Apple Silicon, macOS 15+, GPL-3.0-or-later. Developer-ID-Signatur, Hardened Runtime, Apple-Notarisierung und angeheftetes Ticket. ZIP entpacken und TextUI.app nach Programme ziehen. Die SHA-256-Datei liegt neben dem ZIP.

Weiterhin frühe Version; kein Start auf einem sauberen fremden Mac belegt. GitHub CI prüft Tests und Bundlebuild unter macOS 15.
