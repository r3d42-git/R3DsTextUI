# TextUI 0.1.1

Korrigiert interne Vorschauanker unter macOS 15: Die Erkennung der Offline-Dokumentadresse funktioniert jetzt unabhängig von der Foundation-Version. Zusätzliche Tests prüfen Fragment-, Query- und Pfadvarianten.

Empfohlener Download statt 0.1.0. Apple Silicon, macOS 15+, GPL-3.0-or-later. Developer-ID-Signatur, Hardened Runtime, Apple-Notarisierung und angeheftetes Ticket. ZIP entpacken und TextUI.app nach Programme ziehen. Die SHA-256-Datei liegt neben dem ZIP.

Weiterhin frühe Version; kein Start auf einem sauberen fremden Mac belegt. GitHub CI prüft Tests und Bundlebuild unter macOS 15.
